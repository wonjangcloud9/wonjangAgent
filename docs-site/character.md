# 🎭 캐릭터 — 내 원장, 내 성격으로

원장은 그냥 명령어 모음이 아니라 **터미널에 사는 내 비서**예요. 처음 실행하면 성격부터 고르고, 고른 성격이 대화에 묻어납니다.

## 첫 실행 — 성격 고르기

```bash
wonjang
```

각 원장이 자기 얼굴·목소리로 인사해요:

```
   1) 🌙 다정한 비서 — "안녕하세요, 원장입니다 🌙 무엇을 도와드릴까요?"
   2) 😎 편한 친구   — "야, 나 원장이야. 뭐 도와줄까? 😎"
   3) 🎩 정중한 집사 — "주인님, 원장 대령했습니다."
   4) 😏 시크한 선배 — "왔냐. 뭐 필요한데."
   5) ✨ 밝은 에너지 — "안녕하세요!! 원장이에요!! 오늘도 화이팅이에요 ✨"
```

언제든 다시 고르기:

```bash
wonjang 성격                       # 다시 고르기
wonjang 성격 친구                  # 바로 지정
wonjang 성격 초기화                # 기본으로
```

## 명령마다 자기 말투로

고른 성격은 대화형에서 **명령을 실행할 때마다** 원장의 얼굴·말투로 묻어나요:

```
당신 ▸ 연봉 3600
  😎 원장 ▸ 오케이, 바로 해줄게 👌
  💰 연봉 실수령액 (3,600만원) …
```

집사라면:

```
당신 ▸ 연봉 3600
  🎩 원장 ▸ 분부대로 하겠습니다.
  💰 연봉 실수령액 (3,600만원) …
```

## 나만의 원장 만들기

프리셋이 마음에 안 들면 **직접 만들 수 있어요**. 한 줄 묘사 + 말투만 고르면 끝:

```bash
wonjang 성격 만들기
```

```
  묘사 ▸ 나를 '대장'이라 부르고 츤데레처럼 챙기는 비서
  말투 (1 존댓말 / 2 반말) ▸ 2
  ✅ 나만의 원장이 완성됐어요! 🌟
```

(첫 실행 선택 화면에서도 `6) ✏️ 나만의 원장 직접 만들기`로 들어갈 수 있어요.)

성격은 **사용자가 소유하는 파일**(`SOUL.md`)로 저장돼요. 직접 편집하면 세상에 하나뿐인 내 원장을 만들 수 있어요(헤르메스 에이전트의 SOUL.md처럼).

- **macOS:** `~/Library/Application Support/wonjang/SOUL.md`
- **Linux:** `~/.local/share/wonjang/SOUL.md`

::: tip
[AI로 확장](/ai)을 연결하면, 이 성격이 자연어 대화에도 그대로 적용돼요.
:::
