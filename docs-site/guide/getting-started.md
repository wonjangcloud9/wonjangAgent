# 시작하기

**원장(wonjang)** 은 한국 사람이 매일 쓰는 걸 다 해주는 터미널 개인 비서예요.
가계부·실수령액·디데이·자랑 카드·날씨·환율까지 — **API 키도 로그인도 없이** 설치하면 바로 됩니다.

## 1. 설치

```bash
npm install -g wonjang-agent
```

설치하면 `wonjang` 명령이 생깁니다(플랫폼에 맞는 네이티브 바이너리를 자동으로 받아요).
더 자세한 설치 방법은 [설치](/guide/install)를 참고하세요.

## 2. 첫 실행 — 내 원장 성격 고르기

```bash
wonjang
```

처음 실행하면 **원장의 성격부터 골라요**. 각 원장이 자기 목소리로 인사해요:

```
   1) 🌙 다정한 비서 — "안녕하세요, 원장입니다 🌙 무엇을 도와드릴까요?"
   2) 😎 편한 친구   — "야, 나 원장이야. 뭐 도와줄까? 😎"
   3) 🎩 정중한 집사 — "주인님, 원장 대령했습니다."
   4) 😏 시크한 선배 — "왔냐. 뭐 필요한데."
   5) ✨ 밝은 에너지 — "안녕하세요!! 원장이에요!! 오늘도 화이팅이에요 ✨"
```

고른 성격은 대화에 묻어나요. 자세한 내용은 [캐릭터(성격)](/character)를 참고하세요.

## 3. 바로 써보기

```bash
wonjang 자랑                   # 한 달의 나를 카톡 카드로
wonjang 연봉 3600              # 월 실수령액
wonjang 지출 추가 5만 식비       # 가계부
wonjang 디데이 추가 수능 2026-11-19   # D-day
```

::: tip 한국식 입력 그대로
금액은 `5만` · `1억` · `1.5억` · `50,000` 다 알아듣고, 날짜는 `2026.11.19` · `2026/11/19`도 OK예요.
:::
