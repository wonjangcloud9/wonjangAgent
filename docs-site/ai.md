# 🤖 AI로 확장 (선택)

원장의 **모든 기본 기능은 키 없이** 됩니다. 거기에 **자연어 명령**까지 쓰고 싶다면, 이미 깔린 CLI에 자동 연결하거나 API 키를 설정하면 돼요.

## 이미 깔린 CLI에 자동 연결

[Claude Code](https://claude.com/claude-code)(`claude`)나 Codex(`codex`) CLI가 설치·로그인돼 있으면, 원장이 **자동으로 연결**해요. 따로 설정할 게 없습니다.

```bash
wonjang "다운로드 폴더 정리해줘"
wonjang "이 CSV에서 매출 상위 5개 뽑아줘"
```

## API 키로 연결

```bash
export OPENROUTER_API_KEY=sk-or-...   # OpenRouter
# 또는
export OPENAI_API_KEY=sk-...          # OpenAI 직접
```

::: warning 시크릿은 환경변수로만
API 키 같은 시크릿은 **환경변수로만** 읽어요. 설정 파일이나 코드에 저장하지 않습니다.
:::

## 연결되면 할 수 있는 것

- 파일 정리·이름 일괄 변경
- 문서 작성·요약·번역
- 셸 작업 자동화
- 위 모든 걸 **한국어로** 시키기

그리고 [고른 성격](/character)이 자연어 대화에도 그대로 적용돼요 — 친구로 골랐다면 반말로, 집사로 골랐다면 "주인님"으로 답합니다.

## 안전장치

위험한 명령(`rm -rf`, `sudo` 등)은 무인 모드에서 기본 차단돼요. 실행 전 확인을 거치며, 필요할 때만 명시적으로 허용합니다.
