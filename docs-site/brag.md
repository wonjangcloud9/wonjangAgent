# 🎉 자랑 카드

한 달의 나를, **카톡에서도 안 깨지는 카드 한 장**으로. 습관·집중·지출·디데이가 한눈에 모여 친구한테 자랑하고 싶어져요.

## 한 달 자랑 카드

```bash
wonjang 자랑
```

```
╭──── 원장 카드 · 2026년 6월 ────╮
│ 🔥 가장 긴 연속 운동 15일      │
│ ▓░▓▓░▓▓ ░▓▓▓░░▓ ▓▓▓▓▓▓▓ ▓▓▓▓▓▓▓│
│ 🍅 이번 달 집중 32시간         │
│ 💰 이번 달 지출 240,000원      │
│ 📅 다가오는 날  수능 D-166     │
├────────────────────────────────┤
│ 💬 운동 15일 연속, 잘 쌓고 있어요│
╰─ 나도 만들기 → wonjang-agent ──╯
```

## 클립보드에 바로 복사

```bash
wonjang 자랑 --복사               # 카톡·메모에 바로 붙여넣기
wonjang 자랑 --주                 # 주간 결산
```

::: tip 카톡에 딱 맞게
카드는 고정폭(모노스페이스) 박스라 카톡·메모에 붙여도 줄이 안 깨져요. 좁은 화면엔 `--폭 34`를 권장해요.
:::

## 다른 공유 카드들

원장의 여러 기능이 공유 카드를 지원해요:

```bash
wonjang 전역 2025-03-04 육군 --카드   # 전역 자랑 카드
wonjang 나이 1990-05-15 --카드        # 나이 카드
wonjang 기념일 2024-02-14             # 커플 기념일 카드
wonjang 디데이 카드                   # D-day 카드
wonjang 공휴일 --카드                 # 다음 연휴 D-day 카드(연차 꿀팁 포함)
wonjang 성장                          # 원장이 배운 것 카드(기억·스킬·대화)
```

## 원장은 쓸수록 성장해요

대화하며 배운 사실(기억)·익힌 절차(스킬)가 쌓이고, `wonjang 성장` 카드로
"함께 N일째"와 함께 보여요. 직접 기억시킬 수도 있어요:

```bash
wonjang 기억 "나는 아침형 인간"    # 🌱 기억했어요(4개째)
wonjang 메모리                     # 기억 전체 보기
wonjang 성장                       # 성장 카드 한 장
```

## 매일 한 칸씩 쌓기

자랑 카드가 채워지려면 습관·집중을 쌓아야 해요:

```bash
wonjang 습관 추가 운동
wonjang 습관 완료 운동              # 매일 한 칸
wonjang 집중 25 코딩               # 뽀모도로 타이머
```

매일 한 칸씩 채우면, 한 달 뒤 자랑할 카드가 생겨요.
