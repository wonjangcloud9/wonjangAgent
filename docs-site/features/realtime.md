# 🌐 실시간 정보

날씨·미세먼지·환율 같은 실시간 정보도 **API 키 없이** 바로. 공개 데이터를 직접 가져와요.

## 날씨·미세먼지

```bash
wonjang 날씨 서울
wonjang 미세먼지 서울
```

날씨는 open-meteo, 미세먼지는 환경부 등급 기준이며 둘 다 키가 필요 없어요. 날씨 아이콘은 실제 상태(맑음 ☀️·비 🌧️·눈 🌨️·흐림 ☁️, 밤 맑음 🌙)에 맞게 나오고, **체감온도별 옷차림**(👕 오늘 뭐 입지)도 함께 알려줘요. 비 올 만한 날엔 **☔ 오늘 우산 안내**(오늘 강수확률)까지 — 맑은 날엔 조용히, 필요할 때만 챙겨줘요.

**이번 주 한눈에 + 비 올 확률:**

```bash
wonjang 주간날씨 부산        # 7일 예보(요일·아이콘·최저~최고·강수확률 💧)
```

## 서울 교통

```bash
wonjang 지하철 강남                 # 실시간 도착 정보
wonjang 따릉이 강남역               # 근처 따릉이 대여소
```

## 환율

```bash
wonjang 환율 100 USD               # 원화 환산
```

## 공휴일

```bash
wonjang 공휴일                     # 다음 공휴일·황금연휴까지
```

설날·추석을 포함한 한국 공휴일을 보여주고, **황금연휴**까지 짚어줘요.

::: info 정직하게
검증할 수 없는 실시간 API에 의존하는 기능은 싣지 않아요. 여기 있는 건 모두 공개 데이터로 실측해 검증한 것들입니다.
:::

코인 시세·뉴스 헤드라인 등 더 많은 실시간 기능은 `wonjang 도움`에서 확인하세요.
