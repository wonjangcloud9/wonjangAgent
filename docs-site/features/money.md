# 💰 돈 — 한국 직장인이 매일 묻는 것

가장 자주 쓰는 돈 계산을 한 줄로. 금액은 **한국식 그대로** 알아들어요 — `5만` · `1억` · `1.5억` · `50,000` 다 OK.

## 연봉 실수령액

4대 보험·소득세를 떼고 **월 실수령액**을 보여줘요.

```bash
wonjang 연봉 3600
```

> 2025년 요율·1인 가구·비과세 식대 20만 원 기준 추정치예요.

## 가계부

```bash
wonjang 지출 추가 5만 식비
wonjang 가계부
```

오늘·이번 달 지출, 분류별 막대그래프, **월말 예상 지출**까지 한눈에.

## 대출 상환

```bash
wonjang 대출 30000 4.5 360   # 원금(만원) 연이율(%) 개월수
```

원리금균등·원금균등 **월 상환액**과 **총이자**를 계산해요.

## 예금·적금

```bash
wonjang 예금 1000 3.5 12      # 원금(만원) 연이율(%) 개월수
wonjang 적금 50 3.5 12
```

만기 수령액을 **이자소득세 15.4%** 반영해 계산해요.

## 부가세·할인

```bash
wonjang 부가세 5만           # 공급가·세액 분리
wonjang 할인 5만 30          # 중복 할인가
```

## 더치페이·전월세

```bash
wonjang 더치페이 50000 4     # N빵 1인당(올림 단위까지)
wonjang 전월세 30000 5.5     # 전세 ↔ 월세 전환
```

## 노동 — 퇴직금·연차·야근

```bash
wonjang 퇴직금 300 3         # 월급(만원) 근속연수
wonjang 연차 5               # 입사 N년차 연차 일수
wonjang 연차수당 300 5       # 월급(만원) 미사용 일수 → 통상임금 기준 수당
wonjang 야근 12000 --연장 3  # 시급·연장근로 → 가산수당
```

근로기준법 통상임금(월급÷209×8) 기준이며, 가정이 들어가는 값은 정직하게 '추정'으로 표시해요.

## 자동차세·사업자번호

```bash
wonjang 자동차세 1600        # 배기량·차령별 자동차세
wonjang 사업자번호 124-81-00998
```

`사업자번호` 는 세금계산서·계약서의 **사업자등록번호 오타·허위를 거르는** 국세청 검증번호(체크섬)예요.
`✅ 유효` / `❌ 무효` 로 알려주되, 형식·체크섬만 보는 것이라 *실제 사업자 존재는 국세청 조회가 필요*하다는 점도 정직하게 안내합니다.

::: tip 더 있어요
계산기·환율·코인 등 더 많은 돈 기능은 `wonjang 도움`에서 전체 목록을 볼 수 있어요.
:::
