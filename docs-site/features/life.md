# 🇰🇷 한국 생활 유틸

한국 사람이 실제로 쓰는 것들. GPT한테 묻기 애매한, 딱 떨어지는 변환·표기를 한 줄로.

## 평수 변환

```bash
wonjang 평수 84                     # 84㎡ = 25.4평
```

## 전통 단위

```bash
wonjang 변환 7 자                    # 자·치
wonjang 변환 1 근                    # 근·관
wonjang 변환 5 돈                    # 돈(금은방)
```

자·치·돈·근·관·되·말 같은 한국 전통 단위를 미터법으로.

## 한글 금액 (계약서·수표)

```bash
wonjang 금액 50000                  # 일금 오만원정
```

계약서·수표에 쓰는 **한글 금액 표기**로 바꿔줘요.

## 여권 로마자

```bash
wonjang 로마자 홍길동                # Hong Gildong
```

여권식 로마자 표기 규칙으로 이름을 변환해요.

## 한영 오타 복구

```bash
wonjang 영타 dkssud                 # dkssud → 안녕
```

한글로 치려다 영문으로 친 오타(또는 그 반대)를 복구해요.

## 자소서 글자수

```bash
wonjang 글자수 "자기소개서 내용..." --제한 1000
```

공백 포함/제외 글자수와 제한 대비를 보여줘 자소서·지원서에 딱.

::: tip 더 있어요
초성 추출·BMI·칼로리·세계시간 등 더 많은 생활 유틸이 있어요. `wonjang 도움`에서 전체를 확인하세요.
:::
