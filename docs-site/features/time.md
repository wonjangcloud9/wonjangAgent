# 📅 시간·날짜

중요한 날까지 며칠인지, 한 번 등록하면 원장이 챙겨줘요. 날짜도 한국식 — `2026.11.19` · `2026/11/19` 다 알아들어요.

## 디데이 (D-day)

```bash
wonjang 디데이 추가 수능 2026-11-19
wonjang 디데이                      # 등록한 디데이 목록
wonjang 디데이 카드                  # D-day 공유 카드(카톡 캡처)
```

생일·결혼기념일처럼 매년 반복되는 날은 `--매년`:

```bash
wonjang 디데이 추가 "결혼기념일" 2020-05-20 --매년
```

캘린더로 내보내기:

```bash
wonjang 디데이 내보내기              # .ics 파일로
```

## 기념일

```bash
wonjang 날짜 2024-02-14             # 며칠째 + 다음 기념일 양력 날짜
wonjang 기념일 2024-02-14           # 사귄 지 며칠 — 공유 카드
```

매 100일(100·200·…·900·1000)과 1·2·3주년까지 **다음 기념일을 빠짐없이** 양력 날짜로 알려주는 커플용 기능이에요. "100일 언제야?"를 한 번에.

## 월급날

```bash
wonjang 월급날 25                   # 매달 25일 — 다음 월급날까지 D-day
wonjang 월급날 말일                  # 말일 지급
```

매달 반복되고, 그 달에 없는 날(31일 → 30일 달)도 알아서 처리해요.

## 전역일

```bash
wonjang 전역 2025-03-04 육군        # 입대일 + 군별
wonjang 전역 2025-03-04 공군 --카드  # 전역 자랑 카드
```

전역까지 **D-day · 현재 계급 · 복무 진행률**을 보여줘요. 군별(육군·해병대·해군·공군·사회복무요원) 현행 복무기간으로 계산하며, *만기 전역일 기준(조기전역·휴가·공휴일 미반영)* 임을 정직하게 표시합니다.

## 나이

```bash
wonjang 나이 1990-05-15            # 만나이·세는나이·띠·별자리·살아온 날
wonjang 나이 1990-05-15 --카드      # 공유 카드
```

## 약속·알림

```bash
wonjang 약속 추가 30분 "약 먹기"
wonjang 약속 추가 1시간 "회의" --every @daily   # 반복
```

::: tip
약속 알림이 때맞춰 울리려면 스케줄러가 필요해요: `wonjang cron run`.
:::
