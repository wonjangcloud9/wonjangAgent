# 원장 (wonjang) — 한국인을 위한 개인 비서 🇰🇷

> 가계부·디데이·습관·실수령·날씨까지, **한국 사람이 매일 쓰는 걸 다 해주는** 똑똑한 명령어 비서.
> 단일 바이너리(Rust)라 빠르고, **API 키도 로그인도 없이 설치하면 바로** 쓸 수 있어요.

```bash
npm install -g wonjang-agent
```

설치하면 `wonjang` 명령이 생깁니다(플랫폼에 맞는 네이티브 바이너리를 자동으로 받아요).
**키 설정 없이 지금 바로:**

```bash
wonjang                       # 대화형 모드 — '자랑', '지출 추가 5만 식비'처럼 입력
wonjang 자랑                   # 한 달의 나를 카톡에 자랑하는 카드
wonjang 지출 추가 5만 식비       # 가계부
wonjang 연봉 3600              # 실수령액
```

---

## ✨ 한 달의 나를, 카톡 한 장으로 — `wonjang 자랑`

습관·집중·지출·디데이를 **카톡에서도 안 깨지는 카드 한 장**으로. 친구한테 자랑하고 싶어져요.

```
╭──── 원장 카드 · 2026년 6월 ────╮
│ 🔥 가장 긴 연속 운동 15일      │
│ ▓░▓▓░▓▓ ░▓▓▓░░▓ ▓▓▓▓▓▓▓ ▓▓▓▓▓▓▓│
│ 🍅 이번 달 집중 32시간         │
│ 💰 이번 달 지출 240,000원      │
│ 📅 다가오는 날  수능 D-166     │
├────────────────────────────────┤
│ 💬 운동 15일 연속, 잘 쌓고 있어요│
╰─ 나도 만들기 → wonjang-agent ──╯
```

`wonjang 자랑 --복사` 하면 클립보드에 복사돼요(카톡·메모에 바로 붙여넣기). 주간 결산은 `--주`.

## 🧰 이런 걸 다 해줘요

### 💰 돈 — 한국 직장인이 매일 묻는 것
| 명령 | 하는 일 |
| --- | --- |
| `wonjang 가계부` · `지출 추가 5만 식비` | 오늘·이번 달 지출, 분류별 막대, **월말 예상** |
| `wonjang 연봉 3600` | 4대 보험·소득세 떼고 **월 실수령액**(2025 기준) |
| `wonjang 대출 30000 4.5 360` | 원리금/원금균등 **월 상환액·총이자** |
| `wonjang 예금 1000 3.5 12` · `적금` | 만기 수령액(이자소득세 15.4% 반영) |
| `wonjang 부가세 5만` · `할인 5만 30` | 부가세·중복 할인가 |
| `wonjang 더치페이 50000 4` | N빵 1인당(올림 단위까지) |
| `wonjang 전월세 30000 5.5` | 전세 ↔ 월세 전환 |
| `wonjang 퇴직금 300 3` · `연차 5` · `야근 12000 --연장 3` | 퇴직금·연차 일수·야근수당 |
| `wonjang 자동차세 1600` | 배기량·차령별 자동차세 |

> 금액은 **한국식 그대로** 알아들어요: `5만` · `1억` · `1.5억` · `50,000` 다 OK.

### 📅 시간·날짜
| 명령 | 하는 일 |
| --- | --- |
| `wonjang 디데이 추가 수능 2026-11-19` · `디데이` | 중요한 날까지 **D-day**(요일까지) |
| `wonjang 기념일 2024-02-14` | 사귄 지 며칠 — **공유 카드** |
| `wonjang 약속 추가 30분 "약 먹기"` | 알림(반복 `--every @daily`) |
| `wonjang 나이 1990-05-15` | 만 나이 · **세는나이** · 연 나이 한눈에 |

> 날짜도 한국식: `2026.11.19` · `2026/11/19`, 시간은 `30분` · `1시간 30분` 그대로.

### 🔥 자기관리
| 명령 | 하는 일 |
| --- | --- |
| `wonjang 습관 추가 운동` · `습관 완료 운동` | 습관 잔디 · 연속일(streak) · **통계**(요일 패턴) |
| `wonjang 집중 25 코딩` | 뽀모도로 타이머 + 이번 주·이번 달 누적 |
| `wonjang 일기 "오늘 좋았다"` · `할일 추가 장보기` | 한 줄 일기 · 체크리스트 |

### 🇰🇷 한국 생활 유틸
| 명령 | 하는 일 |
| --- | --- |
| `wonjang 평수 84` | 평 ↔ ㎡ (84㎡ = 25.4평) |
| `wonjang 변환 7 자` · `1 근` | 자·치·돈·근·관·되·말 등 **전통 단위** |
| `wonjang 금액 50000` | 계약서용 **한글 금액**(일금 오만원정) |
| `wonjang 로마자 홍길동` | 여권식 로마자 표기 |
| `wonjang 영타 dkssud` | 한영 오타 복구(dkssud → 안녕) |
| `wonjang 글자수 "자기소개서" --제한 1000` | 자소서 글자수·제한 체크 |

### 🌐 실시간 정보
`wonjang 날씨 서울` · `미세먼지` · `지하철 강남` · `따릉이` · `환율 100 USD` · `공휴일`(황금연휴까지)

### 🛠 도구
`wonjang 비밀번호 16` · `qr "https://..."` · `엑셀`(CSV 분석) · `백업`/`복원` · `해시`·`인코딩` 등

전체 목록은 `wonjang 도움`.

## 🤖 AI 비서로 확장 (선택)

위 기능은 전부 **키 없이** 됩니다. 거기에 **자연어 명령**까지 쓰고 싶다면, 이미 깔린
**Claude Code(`claude`)나 Codex(`codex`) CLI에 자동 연결**되거나, API 키를 설정하면 돼요:

```bash
export OPENROUTER_API_KEY=sk-or-...    # 또는 claude/codex 로그인만 돼 있어도 OK
wonjang "다운로드 폴더 정리해줘"
wonjang "이 CSV 매출 상위 5개 뽑아줘"
```

연결되면 파일 정리·문서 작성·셸 작업까지 한국어로 시킬 수 있습니다.
