내 원장, 내 성격으로 🎭

처음 실행하면 성격부터 골라요. 각 원장이 자기 목소리로 인사하고, 고른 성격이 대화에 묻어나요. wonjang 성격으로 언제든 바꿔요.

🌙다정한 비서"안녕하세요, 원장입니다 🌙 무엇을 도와드릴까요?"
😎편한 친구"야, 나 원장이야. 뭐 도와줄까? 😎"
🎩정중한 집사"주인님, 원장 대령했습니다."
😏시크한 선배"왔냐. 뭐 필요한데."
✨밝은 에너지"안녕하세요!! 원장이에요!! 오늘도 화이팅이에요 ✨"

~/.local/share/wonjang/SOUL.md를 직접 편집하면 나만의 원장도 만들 수 있어요.

1분 설치

설치하면 wonjang 명령이 생깁니다(플랫폼 바이너리 자동 다운로드).

$ npm install -g wonjang-agent

바로 써보기:

wonjang                    # 대화형 — 먼저 성격을 골라요
wonjang 자랑               # 한 달의 나를 카톡 카드로
wonjang 연봉 3600          # 월 실수령액
wonjang 지출 추가 5만 식비   # 가계부

소스에서 빌드(Rust):

$ cargo install --git https://github.com/wonjangcloud9/wonjangAgent
